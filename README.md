ShopSizzle - E-Commerce Website

ShopSizzle is a modern and user-friendly e-commerce website designed to provide customers with a simple and convenient online shopping experience.

Features

- Attractive Home Page
- Product Search
- Shopping Cart
- Wishlist
- Product Categories
- Product Details
- Track Order
- AI Shopping Assistant
- Responsive Design
- Local Storage Support

Product Categories

- Girls Tops & Western Wear
- Men's Clothing
- Watches & Jewellery
- Wallets, Belts & Bags
- Makeup & Beauty
- Accessories

Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Responsive Web Design
